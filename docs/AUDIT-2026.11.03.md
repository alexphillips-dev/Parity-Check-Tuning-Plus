# Comprehensive source audit: 2026.11.03.07

This is the historical audit record for `2026.11.03.07`. The subsequent [runtime cleanup](CLEANUP-2026.11.04.md) removes retired surfaces described below; current behavior and configuration are documented in the README/wiki.

This audit started from development commit `91ed2d87563b38cdba1d18730de9e367c01a14b2` (`2026.11.03.06`). The baseline passed 62 Python tests, 225 browser page cases, and 810 native-grid layout cases. Passing that baseline did not establish the behaviors below: focused fault and boundary fixtures reproduced additional defects, which were repaired and rerun before qualification of the combined candidate.

The resulting development candidate has 109 Python tests, 225 browser page cases, and 945 native-grid layout cases. See [validation commands and acceptance limits](VALIDATION.md). These are local source/package and synthetic-host results; they do not establish physical Unraid acceptance or the absence of every possible defect.

## Integration evidence

Synthetic native commands run only inside temporary host copies. Successful commands update fixture `var.ini`; failed commands leave state unchanged. Destructive paths, shutdown, native command files, backup markers, and notifications are redirected into the fixture. The actual plugin code is executed, with only paths and waiting delays changed in test copies. Existing pure ownership tests continue to cover overlaps, manual pauses, heat transfer, and disabled preferences.

Completion tests retain the verbatim native-monitor section with recorded blob integrity, including overlap while Plus holds its completion lock, actual cancellation/error outcomes, failed delivery/history writes, and pass-through of unrelated notifications. All supported history formats and native parser/stylesheet fixtures are exercised. Catalog pruning removed five unreachable messages; there are no newly untranslated runtime keys. All 42 catalogs retain 363 messages and 45 native exports; runtime translation stays offline.

The combined package contains 124 files. Source bytes, installed references, ownership/modes, archive checksum, root/snapshot manifests, extraction-root preservation, and failed-build preservation are validated. Windows and Linux deterministic rebuilds are compared before publication. Published source, manifest, and package are checked against the exact pushed commit. The wiki is synchronized and pushed separately.

## Compatibility decisions and remaining acceptance

- Existing settings and English state/protocol fields are preserved. No stable release or main-branch promotion is part of this audit.
- Legacy partial markers without kernel identity are discarded without issuing cancellation. A partial check begun with an older build can continue as a normal native operation after update; use native controls deliberately if it should be canceled.
- Invalid schedule settings preserve the last valid cron file. Unsupported cron extensions are rejected. If a schedule fails to apply, correct its saved values and inspect the generated file.
- Critical shutdown uses all readable available disks, including pools, while heat pausing remains an array-operation policy. Unknown temperatures cannot establish a critical condition.
- Native version declaration remains Unraid 6.9.2 minimum. Synthetic version gates do not certify every historical/future Unraid build or third-party mover.
- The documented `history` CLI placeholder and unfinished experimental Docker surface are not promoted to operational features. Native Unraid remains responsible for parity button updates.
- Physical `upgradepkg`, disk I/O, real cron/DST/time-zone behavior, array stop/start/reboot, recon/clear offset behavior, native mover/backup transitions, temperature sensors/spin-up, actual shutdown, and notification channels still need acceptance on an Unraid test server. No physical-host result is inferred from a fixture notification.
- Translations retain structural, formatting, alias, and browser qualification. Native-speaker review is outstanding.
